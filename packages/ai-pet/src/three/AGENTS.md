## pet

木板上的纸艺宠物模型交互；AI 状态与回答由 DOM 宠物目录维护。

**Important:** 这里只消费首页传入的状态和回调，不发起 AI 请求，不控制相机。

### Important files

- `PaperPet.tsx` — 门左侧悬浮木板和小型立体纸艺宠物；米灰方块身体、阶梯边角、简单双眼、短肢与纸折线，无品牌标志或终端面板，消费首页传入的状态及 DOM 内容。

### Implementation notes

- 纸艺宠物的木板位于入口局部 `[-2.3, 0, wallFrontZ + 0.31]`，尺寸为 `[1.7, 0.095, 0.6]`，后沿靠墙；宠物居中放置在木板局部 `x=0`，缩放为 `0.72`，脚底贴住木板顶面。模型使用挤出几何与共享纸纹克隆，复用花坛木纹，不新增在线资源。待机、挥手、思考、回答动作只修改头/身体/手臂 ref，不能操作相机或逐帧更新 React state；不再绘制纸条或睡眠贴纸。
- 宠物按相机在木板局部坐标中的位置计算 Y 轴朝向，抵消门左侧的透视侧面，保持双眼正对访客；不设置固定偏航，也不在待机/思考/悬停时歪头转脸。只绕竖轴旋转整体，脚底继续贴板；位置向量复用，保持呼吸、挥手和眨眼动作，不修改木板或相机。
- 宠物与门共用 `enabled && canEnter && !isOpen` 交互门禁，点击拖动超过 6px 不打开对话。模型中央保留只在键盘聚焦时显示的原生对话入口；该入口和回答明确卸载，不能依赖 Three.js `visible` 隐藏 HTML。完整几何及材质从首次挂载参与预热，自建资源统一释放，不释放共享纹理。减少动态效果时保留静态姿态、关闭呼吸/挥手/眨眼；离场后停止逐帧处理并清理悬停光标。
- 宠物状态与 AI 回答由 `../dom/PaperPetCompanion.tsx` 维护，通过 `HomePage → EntranceDoors` 传入；回答后的追问来自模型 FollowUp，卡片来自 SiteCard，`../paperPet.ts` 只维护类型和首轮入口。面板关闭不取消生成，重新点击助手可继续查看。宠物不再包含睡眠姿态，闲置持续保持清醒。验证模型/键盘/触屏打开、快速重复点击、外部点击关闭、继续生成、长期待机、进门返回、竖屏对话边界与减少动态效果。

- `greeting` 是首页传入的轻量 DOM 导览或执行结果，在对话关闭时显示于模型上方；宽度 ≤600px 或触摸且无悬停时由首页传入 petVisible=false，同时隐藏整个纸宠物木板组、停止帧动画并卸载 HTML；不提供手机端替代入口。
