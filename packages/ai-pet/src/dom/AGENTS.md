## pet

入口 AI 助手状态、键盘入口、回答面板、Markdown 和网站推荐卡片；3D 模型位于 ../three/。

**Important:** 模型接口与凭据只属于后端；面板关闭不取消生成，进门和卸载必须取消请求。

### Important files

- `PaperPetCompanion.tsx` — 入口 AI 助手的状态 hook、键盘唤醒入口和纸张问答面板；首页持有状态，入口 Canvas 仅负责模型和 HTML 锚点。
- `AssistantMarkdown.tsx` — 按需加载的 Markdown/GFM 渲染器，支持 SiteCard 并隐藏 FollowUp 的原始标记；不执行 HTML，不加载模型图片。
- `SiteCard.tsx` — 纸质网站推荐卡片，显示标题、简介和访问链接；不执行模型提供的动作。

### Implementation notes

- 界面使用“AI 向导”“AI 助手”或中性操作提示，不使用昵称或拟人化错误文案。

- 助手初始清醒待机，揭幕后在模型上方显示可点击的简短导览；首次打开后收起开屏气泡，完整欢迎文案来自 `../paperPet.ts`。宽度 ≤600px 或主指针为触摸且无悬停时，模型、木板、气泡、键盘入口和回答全部隐藏，不提供固定向导按钮；切换到手机布局会取消请求并清空会话；`PaperPetTrigger` 使用无文字的 `sr-only` 按钮保留键盘入口，仅聚焦时在宠物区域显示虚线轮廓，不显示“和向导对话”文字标签；桌面入口使用宠物口吻的对话气泡。点击挥手动画约 1.25 秒，但面板打开后即可快捷提问或输入提交，不等待动画结束；只有思考和回答期间禁用提交，禁用按钮使用普通箭头，不显示等待光标。提交后在正文区域显示“正在思考…”直到首个文字块到达，再切换为回答正文与打字机光标，流结束后待机，不设闲置休眠计时器。生成时不能并行提交；进门开始和卸载会取消请求，叉号、Esc 与面板外点击只关闭面板，重新点击助手可继续查看同一请求，过期流不能覆盖新会话。
- 面板标记“AI 对话”，首轮入口由 `../paperPet.ts` 配置，回答后按钮来自模型 FollowUp，点击原样提交 `/api/ai/chat`。保留 160 字输入，仅在内存保留成功的最近问答，进门清空，不持久化；网络失败显示可重试提示，不伪装成本地演示回答。面板打开时 portal 根节点接管外部点击，点击面板外会关闭并恢复宠物显示；只有阶段变化通过 `aria-live` 播报，不逐 token 播报。回复累积后交给按需加载的 `AssistantMarkdown` 渲染，不执行模型 HTML；表格与代码块只在自身区域横向滚动，链接只允许 HTTP(S)。
- `SiteCard` 使用围栏语言名识别，代码体严格为单个已收录 `id`；原始围栏未闭合显示占位，结束后仍无效则显示不可用提示，不能把半截 JSON 暴露为代码或生成链接。卡片资料来自 `服务端 /api/ai/config 与实例 sites 配置`；渲染器和自定义卡片均遵守现有 Tailwind 样式规则。
- `usePaperPet` 只展示模型原文，不从普通文字补卡片。成功 done 后从唯一且合法的 FollowUp 围栏读取 2–3 个候选问题，面板最多展示前两条；首轮 welcome 显示“这里有什么？”和“帮我操作场景”，第二条明确请求打碎一块玻璃。快捷提问位于“回答内容”滚动区域的末尾：短回答时贴住区域底部，长回答时跟在正文后随内容滚动；输入框独立固定在分隔线下，分隔线由输入表单的顶边框绘制。提交新问题时立即清空旧追问，失败、取消和过期流不生成问题。首轮 welcome 入口只在尚未提问时显示，回答后没有固定 followup 或“打开网站”链接列表；访问由模型输出的 SiteCard 提供。
- 快捷提问按钮在普通、悬停和禁用时均使用默认箭头，悬停不变色，不通过 `title` 显示重复文字提示；保留点击提交、禁用保护、键盘焦点提示及完整的 `aria-label`。
- Markdown 自定义渲染组件必须定义在模块层以保持 React 身份稳定；文本和流式状态经渲染器内部 Context 传给围栏组件。不能在每次渲染时重新声明组件，否则面板 pointerdown 更新活跃状态会卸载链接并丢失随后 click。
- 卡片采用标题穿过单层细线边框、简介在下、左下单个“点击访问”按钮的排版，使用已有纸纹、暖灰纸色和小幅不规则圆角；外层 article 不增加边框或投影，避免形成双框。不展示图标色块、标签、收藏或卡片内追问。访问使用新标签页并设置 noopener/noreferrer；界面不再读取或写入收藏存储。
- 面板最大宽度 420px，窄屏保留两侧各 16px，位置依据 visual viewport 约束；验证桌面和非触屏窄窗口的长表格/代码、多卡片内容；320px 手机竖屏和触屏横屏须隐藏宠物与对话，打开时切入手机模式须取消请求。Markdown 首次打开时动态导入，避免进入首页启动包。
- 回答通过首页独立 `z-45` portal 显示在探索提示与导航上方。`PaperPetCompanion` 以 `.paper-pet-reply-anchor` 的投影位置为底部锚点，外框底边保持在宠物锚点上方 12px，尖角指向宠物，横向居中并保留视口边距；不再回退到宠物侧面或下方。顶部距离 visual viewport 顶端 8px，高度用满顶部到宠物之间的可用空间，不设固定高度上限，也不为导航预留整行空白；实际高度不足 180px 时压缩标题与底部间距，快捷提问单行省略但保留完整可访问名称。标题和输入区保持可见，正文与末尾最多两条快捷提问共同滚动；内容变化不改变外框尺寸或位置。正文使用纸色细滚动条和稳定滚动槽，禁止整体横向溢出；新问题开始时正文回顶。仅锚点移动或视口变化时重新定位，卸载清理观察器与事件；验证长回答前后位置一致、顶部始终保留 8px 边距、外框与尖角始终在宠物上方、高屏高度可超过 420px、非触屏窄窗口的视口缩小，以及切换到手机竖横屏时完整隐藏与取消。

- `SceneAction` 与 FollowUp 原始标记都不展示；只在当前请求成功 done 后解析唯一合法动作围栏，由 HomePage 的白名单回调仅执行 `break_glass`，旧后端返回的 `open_scroll` 提示当前场景不支持，不触发其他操作，不从正文、追问或历史补写动作。失败、取消、过期流不执行；关闭面板不取消已请求的操作。执行后展示页面实际结果并保持面板当前开关状态，不自动关闭或重新打开；结果保留在本轮回答，可继续提问。
